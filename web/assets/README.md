# Gino's Pizza Asset Pack v2

Stackable transparent PNG overlays for a top-down pizza builder.

Canvas:
- 1024x1024
- centered
- same alignment across all files

Included:
- 4 crusts x 2 bake states
- 4 sauces x 3 densities
- 3 cheese types x 3 densities + no_cheese
- 12 toppings
- topping densities: light, normal, extra
- topping regions: full, left_half, right_half
- 4 finish overlays
